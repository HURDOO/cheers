# 릴스·쇼츠 제작 도구

## 목적

같은 원곡을 공유하는 여러 응원가 영상을 짧은 구간으로 이어 붙이고, 각 장면에 출처와 응원가 가사를 표시한 9:16 MP4를 만든다. 인스타그램 릴스와 유튜브 쇼츠에 같은 결과물을 사용할 수 있다.

권리 확인 기록은 저장하지 않는다. 사용 허락 확인은 사용자가 직접 책임지고, 제작 데이터에는 실제 영상에 노출할 `화면 출처`만 필수로 저장한다.

## 사용자 흐름

1. 콘텐츠 Admin의 `릴스 제작`에서 `새 릴스`를 누른다.
2. 제작 제목, 공유 원곡, 첫 화면 훅, 마지막 사이트 안내와 게시물 본문을 입력한다.
3. 사용할 순서대로 영상 클립을 추가한다.
4. 클립마다 영상 URL, 원본 기준 시작·종료 초, 장면 제목, 화면 출처와 가사 줄을 입력한다.
5. 필요하면 연결된 응원가를 선택하고 세로 화면의 중심을 왼쪽·가운데·오른쪽 중 하나로 조정한다.
6. 저장 후 `세로 영상 만들기`를 누른다.
7. 완료된 MP4를 Admin에서 재생해 검수하고 내려받는다. 수정이 필요하면 구간이나 문구를 고친 뒤 다시 렌더한다.

작업 상태는 `기획 중`, `소스 필요`, `렌더 준비`, `렌더 완료`, `업로드 승인` 중에서 자유롭게 바꿀 수 있다. 렌더 상태는 별도로 `대기 중`, `렌더 중`, `영상 완성`, `실패`로 표시되며 목록에서 각각 필터링할 수 있다.

## 합성 규칙

- 결과: H.264/AAC MP4, 1080×1920, 30fps
- 화면: 원본을 세로 화면에 가득 차도록 확대하고 사용자가 고른 좌·중·우 중심으로 자른다.
- 오디오: 클립 원음을 유지하고 장면별 음량을 정규화한다.
- 순서: Admin에 놓인 클립 순서를 그대로 사용한다.
- 첫 화면 훅: 전체 영상 시작 후 최대 2.4초간 표시한다.
- 장면 제목: 해당 클립 동안 표시한다.
- 출처: `출처 · {화면 출처}` 형태로 해당 클립이 재생되는 내내 왼쪽 위에 표시한다.
- 가사: 입력한 줄을 해당 클립 길이에 균등하게 나누어 한 줄씩 표시한다.
- 마지막 안내: 전체 영상의 마지막 2.2초에 표시한다.

## 저장 위치

- 기획 데이터: `content/production/reels/<reel-id>.json`
- URL 소스 캐시: `.local/reel-source-cache/`
- 렌더 중간 파일과 결과: `.local/reel-renders/<reel-id>/`
- 최종 영상: `.local/reel-renders/<reel-id>/output.mp4`

URL 소스는 지정한 구간만 내려받으며 같은 URL·구간을 다시 렌더할 때 캐시를 재사용한다. `.local/`은 Git에 포함되지 않는다.

## 실행 환경

Admin 서버가 실행되는 Mac에 다음 도구가 필요하다.

```bash
brew install ffmpeg yt-dlp
```

Admin에서 렌더할 수도 있고 CLI를 직접 실행할 수도 있다.

```bash
npm run reels:render -- <reel-id>
```

렌더러는 macOS 내장 Swift/AppKit으로 Pretendard 한글 자막 PNG를 만든 뒤 FFmpeg로 영상에 합성한다. 영상 플랫폼의 URL 형식이나 다운로드 정책이 바뀌어 소스 취득이 실패하면 Admin에 실패 원인이 표시된다.

## 현재 범위

현재 버전은 컷 편집, 세로 크롭, 원음 연결, 음량 정규화, 출처·제목·가사·마지막 안내 합성과 MP4 다운로드까지 담당한다. 다음 기능은 아직 포함하지 않는다.

- 장면 사이 전환 효과와 박자 자동 정렬
- 가사 줄별 시간을 직접 미세 조정하는 타임라인
- 썸네일 자동 생성
- 인스타그램·유튜브 계정으로 직접 업로드
- 플랫폼 음원 라이브러리의 음원을 자동으로 덧입히는 기능

직접 업로드는 계정과 외부 공개 상태를 바꾸는 작업이므로 별도 승인 흐름을 설계한 뒤 추가한다.
