## 가사와 권리

저작권이 있는 전체 가사·음원·영상 설명·댓글 원문은 저장하지 않는다. 모든 곡은 가사 출처 URL, 구조·주제 요약, 권리 상태를 기록하고 `lyrics.fullTextStored`를 `false`로 유지한다. 사용자 제공, 명시적 이용 허락 또는 퍼블릭 도메인처럼 전문 저장 권리가 확인된 경우만 별도 승인 뒤 저장한다.

## 검증

- `npm run research:validate`: 인벤토리 요약과 제목 원장 일치, 조직 ID, 전역 ID 중복, 근거 참조, YouTube URL·videoId 일치, 곡당 총표본 5개, 댓글 상태, `contextOnly`, 가사 전문 미저장을 검사한다.
- `npm run research:progress`: 398곡 매칭률과 영상·댓글·직접 표본 부족 목록을 출력한다.
- 정본 `data/` 반영은 이 조사 완료와 별개이며 사용자 승인 전에는 수행하지 않는다.
