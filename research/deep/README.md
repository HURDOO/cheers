# 곡별 심층 조사

`research/batches/2026-08-08-current-cheer-song-inventory/`의 제목 인벤토리를 곡별로 검증하는 작업 공간이다.

## 완료 조건

곡 하나가 `deep-reviewed`가 되려면 다음 조건을 모두 충족해야 한다.

1. 공식 구단·학교·응원단 자료와 나무위키 또는 미러의 관련 주장을 각각 확인한다.
2. 원곡·작곡·편곡·개사 관계, 도입 연도, 현재 사용 맥락을 필드별 근거에 연결한다.
3. 상충 주장은 합쳐서 확정하지 않고 각각의 출처와 함께 보존한다.
4. YouTube 영상 5개 이상에서 제목·채널·게시일·설명 요약·댓글 상태를 기록한다. 곡을 직접 담은 공개 영상이 5개보다 적으면 부족 수를 숨기지 않고, 나머지는 조직·발매·행사 맥락 자료임을 `contextOnly`로 명시한다.
5. 공개 댓글은 반복되는 사실 주장과 현장 반응을 요약한다. 댓글이 없거나 비공개면 `unavailable`을 기록하고 가능한 경우 다른 영상으로 표본을 보충한다.
6. 관련 일화와 여담은 출처가 있는 내용만 기록하고 `verified`, `reported`, `anecdotal`로 구분한다.
7. 전체 가사·음원·영상 설명 전문은 저장하지 않는다. 저작권이 있는 노래 가사는 출처 URL, 구조 요약, 권리 상태만 기록하며 짧은 인용도 곡당 총 10단어 이내로 제한한다.
8. 사용자 제공, 명시적 이용 허락, 퍼블릭 도메인 등 전문 저장 권리가 확인된 가사만 별도 승인 뒤 저장할 수 있다.

## 상태

- `collecting`: 조사 중
- `needs-review`: 표본 수는 채웠으나 필드 상충 또는 현재성 확인 필요
- `deep-reviewed`: 완료 조건 충족
- `blocked`: 접근 불가 자료 때문에 같은 조건에서 세 차례 이상 진전하지 못한 경우에만 사용

## 검증

`npm run research:validate`는 배치 JSON 파싱, 상태값, 곡당 서로 다른 YouTube URL·videoId 5개 이상, 출처 참조, 댓글 확인 상태, 가사 전문 미저장, 표본·미해결 합계를 검사한다. 병렬 작성 중인 `collecting` 파일은 완성도 검사에서 건너뛴다. `npm run research:progress`는 현행 제목 인벤토리(현재 398곡) 대비 최소 영상 조건을 채운 완료 곡·초안 곡·영상·댓글 상태를 집계한다.
