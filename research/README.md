# 자료조사 작업 공간

Codex의 1차 조사 결과와 사용자의 검토 결정을 정본 데이터와 분리하는 곳입니다.

## 현재 배치

- [2026 고연전 이벤트 응원가 조사](./batches/2026-09-05-korea-yonsei-games-2026/review.md): 승인된 대학 앵커 49곡의 범위를 고정하고, 전용 초안이 없던 9곡, 기존 초안 중 사용자 미검토 30곡, 스포츠 직접 연결 25곡을 2차 조사한다.
- [2026-08-08 현행 KBO·대학 응원가 제목 인벤토리](./batches/2026-08-08-current-cheer-song-inventory/review.md): 현행 확정·유력 398곡, 재확인 42곡. 곡별 원곡·도입 연도·YouTube 5개 이상 심층 검증의 기준 목록이다.
- [곡별 심층 조사](./deep/README.md): 인벤토리의 각 곡을 최대 5곡 단위 배치로 나눠 공식·나무위키·음원·언론 근거, 원곡과 도입 연도, 사용 맥락, 여담, 상충 주장, 가사 출처·구조, YouTube 5개 이상의 설명·공개 댓글 요약까지 연결한다.

## 소스 우선 파일럿

- [민족의 아리아](./pilots/minjok-ui-aria/README.md): 한 곡에 웹 자료 20건 이상과 YouTube 50건 이상을 연결하고, 원자적 사실 카드·TMI 후보·읽는 문서 초안까지 발전시킨 대규모 샘플이다. 전체 가사와 댓글 원문은 저장하지 않으며 재미있는 전승도 삭제하지 않고 `확인됨·보도됨·전승·미확인`으로 나눠 보존한다.

## 배치 작업 순서

1. `templates/`를 복사해 `batches/YYYY-MM-DD-scope/`를 만듭니다.
2. `scope.md`에 팀, 기간, 대상과 출처 우선순위를 적습니다.
3. Codex는 `candidates.json`과 `evidence.json`만 작성합니다.
4. 사용자는 `review.md`를 읽고 `decisions.json`에 승인, 수정, 기각을 기록합니다.
5. 승인된 항목만 사람이 확인한 뒤 `data/`에 반영합니다.

Codex에 조사시킬 때는 다음 규칙을 프롬프트에 포함합니다.

> `data/`는 수정하지 않는다. 조사 결과는 지정한 `research/batches/` 아래에만 작성한다. 원곡, 도입 연도, 가사, 설명을 각각 근거와 연결하고, 상충하거나 불확실한 정보는 추측해 합치지 않는다.

출처 우선순위는 공식 구단·학교·리그·응원단, 권리자·아티스트·레이블, 신뢰할 수 있는 언론·인터뷰 순입니다. 팬 게시물과 동영상 제목은 단서로 사용할 수 있지만 그것만으로 연도나 원곡을 확정하지 않습니다.

## 대량 제목 인벤토리 검수

`titles.json`과 `inventory.json`으로 먼저 현행곡 제목을 대량 수집한 배치는 로컬 검수 도구의 `목록 검수`에서 확인합니다. 사용자 결정은 같은 배치의 `inventory-decisions.json`에 저장합니다.

- `research-approved`: 후속 심층 조사 대상으로 승인
- `hold`: 현재 사용 여부나 정확한 곡명을 더 확인할 때까지 보류
- `excluded`: 응원가가 아니거나 중복·범위 밖이라 후속 조사에서 제외

후속 Codex 조사에서는 `research-approved` 항목을 `research/deep/batches/*.json`의 곡별 주장과 근거로 발전시킵니다. `npm run research:validate`로 곡당 서로 다른 YouTube 표본 5개 이상과 출처 참조·가사 전문 미저장 원칙을 검사하고, `npm run research:progress`로 전체 진행률을 집계합니다. 목록 승인과 심층 조사 완료는 모두 정본 `data/` 반영 승인과 별개입니다.

## 심층 조사 검수

`npm run review`의 `심층 검수`는 `research/deep/batches/*.json`을 파일별 선택 목록으로 나누지 않고 한데 모읍니다. 조직 필터와 검색을 사용해 곡을 고른 뒤 다음 내용을 대조할 수 있습니다.

- 필드별 주장, 판정, 신뢰도, 판단 메모와 주장에 직접 연결된 출처
- 문서 근거의 발행처·발행일·확인일·요약·지원 필드
- 곡별 YouTube 표본의 제목·채널·게시일·설명 요약·댓글 확인 상태와 댓글 요약
- 사용 맥락, 일화, 미해결 항목, 가사 출처·구조·권리 상태

결정은 원본 조사 JSON을 수정하지 않고 `research/deep/decisions.json`에 `approved`, `changes-requested`, `hold` 중 하나로 저장합니다. `changes-requested`에는 수정 내용을 메모로 남겨야 합니다. 승인 당시의 조사 해시도 함께 기록하므로 이후 다른 세션이 해당 곡의 주장·근거·영상 표본을 바꾸면 검수실에서 재검수 대상으로 표시됩니다.
