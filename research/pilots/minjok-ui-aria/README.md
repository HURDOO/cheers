# 민족의 아리아 소스 우선 심층 조사 파일럿

기존 곡 인벤토리를 그대로 늘리는 대신, 한 곡에 대해 `출처 장부 → 원자적 사실 → TMI 후보 → 읽는 문서`를 끝까지 연결해 보는 샘플이다. 정본 데이터에는 아직 반영하지 않았으며 전체 상태는 `needs-review`다.

## 결과물

- [`web-source-ledger.json`](./web-source-ledger.json): 학교·교우회·권리자·언론·학술·위키 등 웹 근거 29건
- [`youtube-source-ledger.json`](./youtube-source-ledger.json): 시대·행사·공연 형태를 넓힌 YouTube 표본 64건
- [`fact-cards.json`](./fact-cards.json): 한 문장에 한 주장만 둔 원자적 사실 카드 60건
- [`tmi-candidates.json`](./tmi-candidates.json): 흥미도와 주의 문구까지 붙인 편집 후보 32건
- [`article-draft.md`](./article-draft.md): 나무위키식 맥락과 TMI를 사실 등급과 함께 풀어 쓴 문서 초안
- [`review.md`](./review.md): 사람이 승인할 항목, 상충 주장, 추가 취재 과제

## 왜 기존 심층 조사와 분리했나

기존 `research/deep/` 배치는 수백 곡의 현재 사용 여부·원곡·연도를 빠짐없이 훑는 데 초점을 둔다. 이 파일럿은 한 곡에 훨씬 많은 자료를 모아 다음 질문까지 답한다.

- 누가, 언제, 무엇을 근거로 이 곡을 만들었는가?
- 공식 기록과 후대의 전승은 어디서 갈리는가?
- 같은 곡이 응원 OT, 정기전, 축제, 거리, 방송에서 어떻게 다르게 쓰이는가?
- 댓글에서 반복되는 수험생·동문·학부모·타교인의 반응은 무엇인가?
- 재미있지만 아직 증명되지 않은 이야기를 어떻게 버리지 않고 안전하게 보여줄 것인가?

## 판정 언어

| 값 | 의미 |
|---|---|
| `verified` | 공식·직접 자료 또는 독립적인 강한 자료가 일치 |
| `reported` | 취재 기사·영상 설명·편집 자료에 구체적으로 보고됐으나 1차 기록이 부족 |
| `contested` | 출처들이 서로 다른 값을 주장 |
| `anecdotal` | 흥미로운 전승이나 댓글 수용 양상이며 사실 확정에 쓰지 않음 |
| `inferred` | 둘 이상의 확인 자료를 대조해 도출한 명시적 추론 |
| `unresolved` | 필요한 자료를 찾지 못했거나 범위를 확정할 수 없음 |

## 조사 규칙

1. 공식 학교·교우회·응원단, 원저작자·레이블 자료를 가장 먼저 찾는다.
2. 언론 인터뷰와 교내 언론으로 제작 맥락을 교차한다.
3. 나무위키는 TMI 발견용 색인으로 적극 활용하되, 중요한 주장에는 독립 근거를 연결한다.
4. 영상은 제목만 모으지 않고 설명란의 시간표, 게시 시기, 행사·공연 형태와 공개 반응 주제를 기록한다.
5. 영상 업로드 연도와 영상 속 실제 촬영 연도를 분리한다.
6. 현재 관행을 보여주는 영상과 그 관행의 기원을 주장하는 자료를 분리한다.
7. 댓글은 계정명과 원문을 저장하지 않고 반복되는 주제만 익명으로 요약한다.
8. 전체 가사·기사·영상 설명은 복제하지 않는다. 공식 URL, 구조, 주제와 사용자가 승인한 짧은 상징 문구만 남긴다.

## 이번 샘플의 핵심 결론

- `since 2003`은 고려대학교 교우회 연표와 응원단 음악부 취재가 함께 지지한다.
- 정확한 최초 공연 날짜·행사는 아직 확인되지 않았다.
- 곡은 2001년 `Melodramma`의 선율에 1965년 호상비문의 핵심 표현을 압축·재배열한 2003년 응원가다.
- 고려대판 개사자·편곡자·최초 녹음 크레딧은 공개 자료에서 찾지 못했다.
- 오늘날 무반주 합창은 직접 영상으로 확인되지만, 2003년 스피커 고장이 기원이라는 이야기는 1차 자료가 없는 전승이다.
- `서시`에 대한 대응곡이라는 관계는 확인 가능한 서사지만, 두 곡 사이에 직접적인 선율·가사 차용 관계는 없다.

## 검증

저장소 루트에서 다음을 실행한다.

```bash
node scripts/validate-source-pilot.mjs research/pilots/minjok-ui-aria
```

검증기는 출처 ID·URL·영상 ID 중복, 사실·TMI의 끊어진 참조, 허용 판정값, 최소 자료 수, 금지 필드와 원문 과다 저장을 확인한다.
