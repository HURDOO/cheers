# 곡별 심층 검토 계획

이 인벤토리는 제목과 현재 사용 여부를 먼저 모은 1단계다. 사용자와 합의한 품질 기준인 원곡·도입 연도·사용 맥락, 나무위키와 일반 웹 교차 확인, 곡별 YouTube 영상 5개 이상의 제목·설명·공개 댓글 검토는 아래 후속 배치에서 수행한다.

## 공통 산출물

각 곡마다 다음을 기록한다.

- 정식 제목, 통용 별칭, 조직·캠퍼스
- 원곡·작곡·편곡·개사 관계와 각 필드의 신뢰도
- 도입 연도 또는 가장 오래 확인된 사용 연도
- 연도가 확정되지 않으면 `YYYY (추정)`과 근거·상충 주장을 함께 보존
- 현장 사용 맥락과 현재성 근거
- YouTube 영상 최소 5개: URL, 채널, 제목, 게시일, 설명의 관련 내용, 공개 댓글에서 반복되는 사실 주장과 반응
- 댓글 비공개·차단·삭제 시 `unavailable`로 기록하고 다른 영상으로 표본을 보충
- 전체 가사·음원은 저장하지 않고, 사용자 승인 전에는 `data/`에 반영하지 않음

## 검토 순서

1. `재확인` 곡은 먼저 최근 사용 여부와 고유곡 여부를 판정한다.
2. 현행 확정곡의 원곡·연도·별칭을 조사한다.
3. 곡별 영상 5개 이상을 채우고 설명·댓글의 사실 주장을 출처 유형별로 분리한다.
4. 같은 원곡을 공유해도 가사와 조직이 다르면 별도 응원가로 유지한다.
5. 제목만 다른 같은 곡, 메들리·판본·짧은 상황 버전은 사용자 검토용 병합 후보로 제시한다.
